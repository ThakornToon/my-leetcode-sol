### <a id="how-to-set-this-up-yourself"></a>⚙️ How to Set This Up Yourself

If you want to sync your LeetCode submissions to GitHub and generate an organized README like this, follow these steps:

### 1. Automated Sync via GitHub Actions
1. Create a new GitHub repository (e.g., `leetcode-solutions`).
2. Get your LeetCode session cookies (`LEETCODE_SESSION` and `csrftoken`) from your browser's Developer Tools (`F12` -> Application -> Cookies -> `leetcode.com`).
3. In your GitHub repository, go to **Settings** -> **Secrets and variables** -> **Actions**, and add two repository secrets:
   - `LEETCODE_SESSION`
   - `CSRFTOKEN`
4. Create a GitHub Action workflow file at `.github/workflows/leetcode.yml` with the following configuration:

```yaml
name: Sync LeetCode

on:
  workflow_dispatch:
  schedule:
    - cron: "0 0 * * *"

jobs:
  build:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: "3.x"
      - run: python -m pip install requests
      - uses: ThakornToon/leetcode-sync@master   # you can select a different repository if needed
        with:
          github-token: ${{ secrets.GITHUB_TOKEN }}
          leetcode-session: ${{ secrets.LEETCODE_SESSION }}
          leetcode-csrf-token: ${{ secrets.CSRFTOKEN }}
          destination-folder: "solutions"
      - run: python generate_readme.py
      - name: Commit and push generated README files
        run: |
          git config user.name "github-actions[bot]"
          git config user.email "41898282+github-actions[bot]@users.noreply.github.com"
          git add README.md EASY.md MEDIUM.md HARD.md TOPICS.md
          if ! git diff --cached --quiet; then
            git commit -m "Update generated LeetCode README files"
            git push
          else
            echo "No generated README changes to commit."
          fi
```

I initially used [`joshcai/leetcode-sync@v1.5`](https://github.com/joshcai/leetcode-sync) because I liked how it organized solution files and handled commits. I later ran into LeetCode API requests being blocked by Cloudflare, so I adapted the v1.5 code. You can find my adapted version at [`ThakornToon/leetcode-sync`](https://github.com/ThakornToon/leetcode-sync).

This Cloudflare issue is resolved in `leetcode-sync` v1.6 and later, but you will need to update `generate_readme.py` to work with those versions. I recommend using the latest version because it fixes fetching submissions for Premium problems. Some smaller improvements are still waiting for their pull requests to be merged. If you want to customize the project to your preferences, you can fork [`joshcai/leetcode-sync`](https://github.com/joshcai/leetcode-sync).

### 2. Generate README.md Automatically
You can use a Python script to scan your solution folders, fetch problem details (ID, title, difficulty) and topics from a public metadata dataset, sort them, and update your `README.md` automatically.
